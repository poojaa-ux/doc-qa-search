# Document Q&A using Semantic Search

Upload a PDF/TXT file, ask a question, and the app shows the parts of the document that best match it.
Tools: Python, Flask, MongoDB Atlas, sentence-transformers.

## How to run
1. pip install -r requirements.txt
2. Copy config_example.py to config.py and add your MongoDB link
3. python app.py
4. Open http://localhost:5000
